# Conversor de Unidades

¡Bienvenido/a al repositorio de **Conversor de Unidades**! Una herramienta práctica, ligera y eficiente desarrollada para convertir diferentes tipos de unidades de medida de forma rápida y sencilla.

## 🌟 Características Principales

* **Conversión Múltiple:** Soporte para diversas categorías de unidades (como longitud, peso, temperatura, entre otras).
* **Resultados Instantáneos:** Visualiza los cálculos de conversión en tiempo real a medida que ingresas los datos.
* **Interfaz Limpia y Minimalista:** Diseñada para ofrecer una experiencia de usuario fluida y sin distracciones.
* **Optimizado para Web:** Funciona directamente en cualquier navegador moderno sin necesidad de instalaciones complejas.

## 🚀 Tecnologías Utilizadas

Este proyecto está construido con tecnologías web esenciales:

* **HTML5** para la estructura de la interfaz.
* **CSS3** para el diseño responsivo y el estilo visual.
* **JavaScript** para la lógica de conversión y la interactividad dinámica.

## 📦 Instalación y Uso

Si quieres probar o ejecutar este proyecto en tu entorno local, sigue los siguientes pasos:

1. Clona este repositorio en tu computadora:

   ```bash
   git clone https://github.com/VictoriaBalanda/coversor-de-unidades.git
   ```

2. Navega hasta la carpeta del proyecto:

   ```bash
   cd coversor-de-unidades
   ```

3. Abre el archivo principal (por ejemplo, `index.html`) directamente en tu navegador web de preferencia.
